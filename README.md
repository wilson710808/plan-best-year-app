# 📅 规划最好的一年 - AI 引导式个人成长 App

> 基于《规划最好的一年》书籍理念，AI 扮演个人成长教练，引导用户完成年度规划。

## ✨ 核心功能

### 🧭 四步引导流程
1. **打开认知** - 探索你真正想要的
2. **挖掘需求** - 找到目标背后的渴望
3. **设定目标** - 清晰可衡量的 SMART 计划
4. **陪伴执行** - AI 教练每日跟进

### 🤝 AI 伙伴圈
三种性格迥异的 AI 教练陪你成长：
- **务实派** 🤓 - 泼冷水提醒你现实
- **鼓励派** 🌟 - 快放弃时推你一把
- **好奇派** 🔮 - 帮你探索可能性

### 🎯 目标管理
- 多维度目标追踪（事业、健康、财务、关系、成长、贡献）
- 进度可视化
- 里程碑管理

### 📝 每日复盘
- 结构化复盘模板
- 心情追踪
- 历史回顾

## 🛠 技术栈

- **前端框架**: React 18
- **构建工具**: Vite
- **路由**: React Router v6
- **样式**: CSS3 (移动端优先设计)
- **状态管理**: React Hooks (useState, useContext)

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 📱 设计特点

- **移动端优先**: 专为手机用户优化
- **温暖配色**: 橙色主题，温暖但专业
- **简洁界面**: 单手操作友好
- **数据持久化**: LocalStorage 本地存储

## 🎨 页面结构

```
├── 欢迎页 (WelcomePage)
├── 规划引导 (GuidePage) - 四步 AI 引导流程
├── AI 伙伴圈 (PartnersPage) - 多角色切换
├── 目标进度 (GoalsPage) - 目标追踪
└── 每日复盘 (ReviewPage) - 日/周复盘
```
